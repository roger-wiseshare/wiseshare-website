# 喵數獨：玩家資料與排行榜（Google Apps Script）

GitHub Pages 只能放靜態檔案，網頁沒辦法直接把資料寫回 GitHub。
所以玩家名稱、積分、總遊戲時長、各難度最短時間，是由遊戲網頁送到這支 Apps Script，存進一份 Google 試算表，排行榜也從這裡讀取。

## 安裝（約 5 分鐘，做法與官網問卷相同）

1. 建一份新的 Google 試算表，取名「喵數獨玩家資料」。
2. 上方選單「擴充功能 → Apps Script」，把預設內容全部刪掉，貼上同資料夾 `Code.gs` 的全部內容，存檔。
3. 右上「部署 → 新增部署作業」，類型選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 第一次會要求授權，照畫面同意即可（只會存取這份試算表）。
5. 複製部署後的「網頁應用程式網址」（結尾是 `/exec`）。
6. 把網址交給 Claude，或自己填進 `meowdoko/index.html` 裡的這一行後推送：

   ```js
   const ENDPOINT = '';   // ← 貼上網址
   ```

**更新程式時**：把新的 `Code.gs` 貼上取代，存檔後到「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本：新版本 → 部署」，網址不會變。

之後試算表會自動出現「玩家」分頁，每位玩家一列。程式修改後要再「部署 → 管理部署作業 → 編輯 → 新版本」才會生效。

## 資料欄位

玩家ID（瀏覽器隨機產生）、流水號、名稱、累積積分、總遊戲時長（秒）、通關盤數、各難度最短通關時間（秒）、最後更新。

## 名稱規則

- 名稱只能是英數字、最多 12 字，**不分大小寫**，全部玩家不可重複（check／claim）。
- 遊戲啟動時用名稱查詢（load）：存在就帶入積分、總時長、最短時間；不存在就從 0 分重新開始。

## 注意

- 沒有登入機制：玩家以「這個瀏覽器」為單位，換裝置或清除瀏覽資料會被視為新玩家。
- 積分由瀏覽器回報，有心人可以自行竄改；排行榜適合娛樂，不適合發獎金。
- 排行榜只公開名稱與積分，不會公開玩家 ID。
